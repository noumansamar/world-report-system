## User Stories
**1. Countries by Population**
As a user I want to see all countries sorted by population, largest to smallest
So I can compare countries by population.

**2. Cities by Population**
As a user I want to see all cities sorted by population, largest to smallest
So I can compare cities by population.

**3. Capital Cities by Population**
As a user I want to see all capital cities sorted by population, largest to smallest
So I can compare how populated different capital cities are.

**4. Top N Populated Cities**
As a user I want to specify a number N and see the N most populated cities in the world
So I can quickly view a focused list of the largest cities without scrolling through all of them.

**5. Population Breakdown Per Country**
As a user I want to see each country's total population split into people living in cities and people not living in cities, with percentages
So I can understand urbanisation levels across countries.

**6. Population Lookup by Scope**
As a user I want to look up the population of the world, a continent, a region, a country, a district, or a city
So I can retrieve population figures at whatever level of detail I need.

**7. Language Speaker Statistics**
As a user I want to see how many people speak Chinese, English, and Spanish, ranked from greatest to smallest, with each as a percentage of world population
So I can understand the global reach of major languages.

**8. Documented Evidence of Requirements**
As a project stakeholder I want the README to clearly show how many requirements have been implemented, with screenshots as evidence
So I can quickly verify the system meets its specification without running the code myself.
